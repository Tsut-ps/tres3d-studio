# 使い方

## 基本

1. 左のパレットからブロックをドラッグ（クリックでも追加）する
2. 中央のワークスペースで入れ子に積む。形状・素材・動きは、ブロックの中の「＋」や空の受け口に入れる
3. ブロックを選ぶと、右下のインスペクタにプロパティが出る
4. 上部の「コード」で、書き出されるコードを見る

「＋ 動き」「＋ ブロック」や空の「形状をここへ」を押すと、パレットが合う種類に移り、追加先が強調されます（Esc で解除）。
受け口は、合うものだけが入ります（形状＝ひし形、素材＝丸、動き＝三角）。

## 操作

操作は Unity に合わせています。

| 操作 | 内容 |
| --- | --- |
| Q / W / E / R | 選択のみ / 移動 / 回転 / 拡大のギズモ（プレビュー左上のボタンでも可） |
| Ctrl を押しながらドラッグ | ギズモでグリッドにスナップ（0.5・15°・0.1） |
| F | 選択したブロックに寄る（何も選んでいなければ全体）。自由視点のみ |
| 右ドラッグ / 中ドラッグ / ホイール | 視点の回転 / 平行移動 / ズーム |
| Alt+左ドラッグ / Alt+右ドラッグ | 視点の回転 / ズーム |
| Ctrl(⌘)+クリック / Shift+クリック | 選択の追加・解除 / 範囲選択（ブロック欄でもプレビューでも） |
| Ctrl+A / D / C / V, Delete | すべて選択 / 複製 / コピー / 貼り付け, 削除（複数選択ならまとめて） |
| Ctrl+Z / Ctrl+Shift+Z (Y) | 取り消し / やり直し |
| F2 / 見出しをダブルクリック | 名前の変更（`name` として書き出される） |
| ↑↓ / ←→ | 選択を動かす（Shift で範囲）/ 閉じる・親へ、開く・中へ |
| 右クリック | 複製・コピー・貼り付け・無効化・上へ下へ・削除・コードで見る |
| 数値欄をドラッグ | 左右にドラッグして値を変える（Shift で 1/10）。クリックなら直接入力。タッチでは働かない |
| 領域の境界をドラッグ | プレビューの大きさを調整（ダブルクリックで戻す、矢印キーでも可）。「拡大」で一時的に大きくもできる |

## プレビュー

- **視点は 2 種類**: 自由視点は作業用の別カメラで、切り替えても位置を覚えている（↺ で初期位置）。カメラ視点は、ブロックのカメラから見た絵（書き出したコードの画面）で、見るだけ。カメラのブロックが無いと選べない
- **表示**: 「表示」でグリッド・座標軸・FPS を出し入れする。プレビューだけの表示で、書き出すコードには入らない
- **ブロックとの連動**: ブロックを選ぶ／なぞると、プレビューに枠（選択は黄、ホバーは水色）が出る。プレビューのメッシュなどをクリックすると、該当ブロックが選ばれる
- **スナップと整列**: 移動のドラッグは、ほかのオブジェクトの面・中心・床に約 10px 以内でそろう（ガイド線が出る。磁石のボタンで切り替え、Ctrl 中はグリッドスナップに替わる）。2 つ以上選ぶと「整列」が使える（床に置く / X・Y・Z の最小・中央・最大にそろえる / 等間隔）
- **動きとギズモ**: ギズモで動かしているブロックの動き（回転・上下など）は、選んでいるあいだ止まる。動きを外すと、値の位置・向き・大きさに戻る

## コードとの対応

コードは、広い画面では下に固定表示（上端のつまみで高さを調整）、狭い画面ではダイアログで出ます。

- 各行の左に、そのブロックの色の帯が付く
- 行をクリックするとブロックが選ばれ、ブロックを選ぶと対応する行が光ってそこへスクロールする

## 書き出したコードを使う

1. `npm create vite@latest my-scene -- --template vue-ts` でプロジェクトを作る
2. 「コード」に出るインストールコマンド（例: `pnpm add three @tresjs/core @tresjs/cientos`）を実行する
3. 出たファイルを `src/` に置き、`vite.config.ts` を置き換える

`textures.ts` や `StudioEnv.ts` が出たときは、それも `src/` に置きます。アップロードした画像は、`/path/to/image.png` の部分を実際のファイルに書き換えてください。

## 保存

編集内容は、少し待ってからブラウザに自動で保存されます（上部に「自動保存 時刻」）。次に開くと、続きから復元されます。保存できない環境では「保存できません」と出ます。
保存はブラウザごとです。ほかの端末や人とは共有されないので、受け渡しは JSON の書き出し・読み込みで行います。

## 見た目の読み方

- 配色はダークのみ。文字は白系で統一し、色付きブロックの上も白文字（選択中・主ボタンは青紫）
- 「変更 N」は、そのブロックで既定値から変えたプロパティの数（インスペクタ上部は「変更 N / 全 M」）。グループ右の「N 項目」は、その中のプロパティの数
- 色と形で見分けられる: 種類ごとのアイコン、XYZ は赤・緑・青、スライダーの小さな目印は既定値
- ブロック見出しの目・複製・削除は、カーソルを乗せた／選んだブロックだけに出る。見出しには主要な 1〜2 項目だけを出し、ほかはインスペクタで編集する

## 対応範囲

### ブロック

| 分類 | 内容 |
| --- | --- |
| オブジェクト | メッシュ、グループ、点群、線、線分、スプライト、輪郭線、角丸の箱、スーパーフォーミュラ |
| 形状・素材 | 形状 14 種、素材 18 種（標準・物理・トゥーン・ガラス・ホログラムなど） |
| ライト・カメラ | ライト 5 種、カメラ 2 種、コントロール 2 種 |
| 背景・環境 | フォグ、背景色、空、星空、影、きらめき、煙、雨・雪、レンズフレア、スタジオ環境光、補助線 |
| エフェクト | コンポーザー + 25 種（ブルーム、被写界深度、グリッチなど） |
| 動き | 回転、上下、周回、拡縮、色変化、ホバー、クリック、浮遊、カメラ目線 |
| シーン設定 | TresCanvas の主要プロパティ |

three.js と TresJS の全部ではなく、上の約 100 種です。

### プロパティ

各ブロックのプロパティは、ライブラリから自動で拾っています。設定できる項目の大半（目安は 9 割強）が、インスペクタに出ます。

| | 内容 |
| --- | --- |
| 対応 | 数値・角度・真偽・列挙・色・ベクトル・テクスチャ・JSON で表せる値。ライトの影（`shadow-*`）。ライブラリを更新すると新しい項目も出る |
| 非対応 | 内部の値（`uuid`・行列など）、コールバック（関数を渡す項目）、`userData`・`pivot`、素材の `blendAlpha`、ライトの `target`、カメラの行列、形状のデータそのもの（`attributes`・`index`）、コントロールの `keys`・`mouseButtons`・`touches` |

## 既知の制約

- ネットワークに出られない環境（公開ページなど）では、`Environment` のプリセット、URL 指定のテクスチャ、ファイルのダウンロードは使えない。代わりに「スタジオ環境光」、内蔵プリセットと画像のアップロードを用意している
- `SoftShadows` の `samples` / `focus` は three r186 との相性が悪いため非対応
- ヘルパー類は引数で作られるため、値の変更で作り直される
- 独自の GLSL シェーダーと独自ジオメトリの編集は未対応
- `power` と `intensity`、`ior` と `reflectivity` は three.js 内部で連動する（インスペクタでは鎖のマーク）
- プレビューの枠表示とクリック選択は、メッシュ・点・線・スプライトとライト・カメラが対象。グループと環境光は対象外
- ギズモは、位置を持つオブジェクト（グループ・ライト・カメラを含む）に出る。環境光、形状・素材・動き、エフェクトには出ない。プレビューで選べないグループも、ブロックを選べばギズモで動かせる
- クリックの「ジャンプ」は、プレビューと書き出したコードで動きの大きさが少し違う
