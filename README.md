# Tres3D Studio

ブロックを積んで TresJS のシーンを組み立て、その場でプレビューできるツールです。
書き出したコードは、そのまま Vue + TresJS のプロジェクトで動きます。
TresJS の非公式ツールです。

## 使い方

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # dist/index.html に単一ファイルで出力
```

- 左のパレットからブロックをドラッグ（クリックでも追加）
- ブロックの中の「＋ 動き」「＋ ブロック」や、空の「形状をここへ」を押すと、パレットが合う種類に移り、追加先が強調される（パレット上部に「追加先」）。そこでブロックを押すとその場所へ入る（置けないものはうすい）。Esc か × で解除。狭い画面ではパレットのタブへ切り替わる
- 中央のワークスペースで入れ子に積む。形状・素材は「穴」に入れる
- ブロックを選ぶと右下のインスペクタにプロパティが出る
- 上部の「コード」で App.vue / Scene.vue / vite.config.ts などを書き出し。広い画面では下に固定表示（境界をドラッグで高さ調整）、狭い画面ではダイアログ
- 領域の境界をドラッグでプレビューの大きさを調整（ダブルクリックで元に戻す、矢印キーでも可）。プレビュー下の「拡大」で一時的に大きくできる
- 操作は Unity に合わせている

| 操作 | 内容 |
| --- | --- |
| Q / W / E / R | 選択のみ / 移動 / 回転 / 拡大のギズモ（プレビュー左上のボタンでも可）。Ctrl を押しながらドラッグでスナップ（0.5・15°・0.1） |
| F | 選択したブロックに寄る（何も選んでいなければ全体） |
| 右ドラッグ / 中ドラッグ / ホイール | 視点の回転 / 平行移動 / ズーム。Alt+左ドラッグで回転、Alt+右ドラッグでズーム |
| Ctrl(⌘)+クリック / Shift+クリック | 選択の追加・解除 / 範囲選択（ブロック欄でもプレビューでも） |
| Ctrl+A / Ctrl+D / Ctrl+C / Ctrl+V / Delete | すべて選択 / 複製 / コピー / 貼り付け / 削除（複数選択ならまとめて） |
| F2 / 見出しをダブルクリック | 名前の変更（`name` として書き出される） |
| ↑↓ / ←→ | 選択を動かす（Shift で範囲）/ 閉じる・親へ、開く・中へ |
| 右クリック | 複製・コピー・貼り付け・無効化・上へ下へ・削除・コードで見る のメニュー |
| 数値欄をドラッグ | 欄を左右にドラッグして値を変える（Shift で 1/10 の細かさ）。クリックなら、これまでどおり直接入力。タッチ操作では働かない |
| プレビュー下のバー | 「表示」でグリッド・座標軸・FPS を出し入れ（プレビューだけの表示で、書き出すコードには入らない）。「自由視点 / カメラ視点」で見方を切り替え、↺ で自由視点を初期位置に戻す |

- ギズモで動かしているブロックの「動き」（回転・上下など）は、選択しているあいだ止まる。複数選択してギズモで動かすと、同じ親のブロックにも同じ変化量が加わる
- 視点は 2 種類。自由視点は作業用の別カメラで、切り替えても位置を覚えている。カメラ視点は、ブロックのカメラから見た絵（書き出したコードの画面）で、見るだけ。カメラのブロックが無いと選べない
- カメラ視点では、使われているカメラ自身にギズモは出ない。カメラのブロックを動かすときは自由視点にするか、インスペクタで値を入れる（Fで寄るのも自由視点のみ）
- コードとブロックの対応: コードの各行の左に、そのブロックの色の帯が付く。行をクリックするとブロックが選ばれ、ブロックを選ぶと対応する行が光って、そこへスクロールする（なぞると範囲が薄く光る）。ブロックの右クリック「コードで見る」でも開く
- スナップと整列: 移動ギズモのドラッグは、ほかのオブジェクトの面・中心にそろう（約 10px 以内。ガイド線が出る）。プレビュー上のバーの磁石で切り替え、Ctrl を押している間は代わりにグリッドスナップ。2 つ以上選ぶと「整列」が使え、床に置く／X・Y・Z の最小・中央・最大にそろえる／等間隔にできる
- 自動保存: 変更は少し待ってブラウザに自動で保存され、次に開くと続きから復元される（上部に「自動保存 時刻」、前回の続きを開いたときは通知）。保存できない環境では「保存できません」と出る。ブラウザごとの保存なので、ほかの端末・人とは共有されない
- 初回の案内: はじめて開いたときに 4 つの手順のカードが出る（「もう出さない」で非表示。上部の「？」でいつでも再表示）
- サンプルの切り替え中は「読み込み中」を重ねて表示（切り替え時に選択・追加先・メニューなども初期化）
- 動きを外すと、ブロックの位置・向き・大きさの値に戻る
- ブロックとプレビューは連動。ブロックを選ぶ／なぞるとプレビュー側に枠（選択は黄、ホバーは水色）が出て、プレビューのメッシュなどをクリックすると該当ブロックが選ばれる（ドラッグで視点を動かしたときは選ばない、何もない所をクリックでシーン設定）
- 配色はダークのみ。文字は白系で統一し、色付きブロック・ボタンの上も白文字（選択中・主ボタンは青紫）
- 「変更 N」は、そのブロックで既定値から変えたプロパティの数（インスペクタ上部は「変更 N / 全 M」）。グループ右の「N 項目」は、その中のプロパティの数
- 「コピーしました」などの通知は、ダイアログが開いていても最前面に出る
- 色と形で見分けられる: 種類ごとのアイコン、XYZ は赤・緑・青、スライダーは、つまみより左を色付き・右を暗い色にして、小さな目印で既定値を示す、形状＝ひし形／素材＝丸／動き＝三角の受け口（ドラッグ中は置けない場所がうすくなる）
- ブロック見出しの目・複製・削除は、カーソルを乗せた／選んだブロックだけに表示。インスペクタの英語名（`position` など）も、行にカーソルを乗せたとき・検索中だけ表示（タッチ端末は常に表示）
- ブロックの見出しには主要な 1〜2 項目だけを出し、それ以外はインスペクタで編集（狭い画面では見出しの入力欄は省略）

## 対応範囲

| 分類 | 内容 |
| --- | --- |
| three.js | オブジェクト、カメラ、ライト、ヘルパー、形状 14 種、素材 14 種、フォグ、背景色 |
| cientos | コントロール、空、星、影、きらめき、煙、雨、Edges、特殊素材など |
| post-processing | コンポーザー + エフェクト 25 種 |
| 動き | 回転、上下、周回、拡縮、色変化、ホバー、クリック |
| シーン設定 | TresCanvas の主要プロパティ |

## プロパティを網羅する仕組み

プロパティ一覧は手書きせず、起動時に three.js のクラスを実際に生成して取り出しています。

- インスタンスのプロパティを、プロトタイプを遡って列挙し、型（数値・角度・色・ベクトル・列挙・テクスチャなど）に分類
- 形状の引数は `.parameters` の並び順から取得
- cientos / post-processing は Vue コンポーネントの `props`（型と既定値）から取得
- ライブラリを更新すると、新しいプロパティも自動で現れる

インスペクタには、検索、変更済みだけの絞り込み、グループの折りたたみ、1 項目ごとの戻すボタン、
ラベルのドラッグによる数値調整（Shift で微調整）があります。変更したものだけを保持し、既定値と同じになれば自動で外れます。

## 公開ページの制限

公開ページはネットワークに出られないため、次は使えません。

- `Environment` のプリセット（代わりに通信不要の「スタジオ環境光」を用意）
- URL 指定のテクスチャ（内蔵プリセットと画像のアップロードは可）
- ファイルのダウンロード（コードと JSON はコピーして使う）

## 既知の制約

- `SoftShadows` の `samples` / `focus` は three r186 との相性が悪いため非対応
- ヘルパー類は引数で作られるため、値の変更で作り直される
- 独自の GLSL シェーダーと独自ジオメトリの編集は未対応
- `power` と `intensity`、`ior` と `reflectivity` は three.js 内部で連動する（インスペクタでは鎖のマーク）
- プレビューでの枠表示とクリック選択は、メッシュ・点・線・スプライトとライト・カメラが対象。グループと環境光は対象外
- ギズモは、位置を持つオブジェクト（グループ・ライト・カメラを含む）に出る。環境光、形状・素材・動き、エフェクトには出ない。プレビューのクリックで選べないグループも、ブロックを選べばギズモで動かせる
